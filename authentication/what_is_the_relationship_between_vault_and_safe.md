### **✅ CyberArk の Vault とは？**
**CyberArk Vault** は、**機密情報（認証情報、パスワード、SSHキー、証明書など）を安全に保管・管理するためのセキュアなストレージ** です。  
企業の **特権アカウント管理（PAM: Privileged Access Management）** の中心的なコンポーネントとなります。

🔹 **イメージ:**  
```
CyberArk Vault（保管庫）
  ├── Safe（金庫）
  │    ├── アカウント1（DBパスワード）
  │    ├── アカウント2（Windows管理者パスワード）
  │    ├── アカウント3（SSHキー）
  │    ├── 証明書情報  など…
  ├── ユーザー管理
  ├── アクセス制御
  ├── ログ監査
```
**➡️ Vault（保管庫）の中に Safe（金庫）があり、Safe 内に機密情報が格納されるイメージ。**

---

## **✅ Vault の中に Safe があるイメージ？**
**はい、その通りです！**  
CyberArk では、**Vault（システム全体のセキュアストレージ）の中に Safe（論理的な保管場所）があり、Safe 内にパスワードや認証情報が格納されます**。

| **コンポーネント** | **説明** |
|-----------------|----------------------|
| **Vault（保管庫）** | すべての機密情報を保存するセキュアなストレージ |
| **Safe（金庫）** | Vault 内にある論理的なコンテナ（アクセス制御単位） |
| **アカウント情報** | Safe の中に保存されるパスワードや認証情報 |

💡 **例:**  
- **`DB-Credentials-Safe`** → **データベースの認証情報を保管**  
- **`Windows-Admin-Safe`** → **Windows 管理者パスワードを保管**  
- **`SSH-Keys-Safe`** → **サーバーの SSH 鍵を保管**  

---

## **✅ CyberArk の Vault 以外の主要コンポーネント**
CyberArk は Vault だけでなく、**特権アカウントを管理・監査するための多くのコンポーネント** を提供しています。

| **コンポーネント** | **説明** |
|-----------------|----------------------|
| **Vault（保管庫）** | **認証情報を安全に保存**（Safe の中に格納） |
| **PVWA（Privileged Web Access）** | **Web UI から Vault を操作**（管理者やユーザーがパスワード管理を行う） |
| **CPM（Central Policy Manager）** | **パスワードのローテーション・更新を自動化** |
| **PTA（Privileged Threat Analytics）** | **異常な特権アカウントの使用を検知** |
| **PSM（Privileged Session Manager）** | **リモートセッションの記録・監視**（RDP、SSHなど） |
| **AIM（Application Identity Manager）** | **アプリケーション向けのシークレット管理** |
| **EPM（Endpoint Privilege Manager）** | **エンドポイントの特権管理（ローカル管理者権限制御など）** |
