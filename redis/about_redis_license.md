Redisを商用で無料で使用するのは禁止されていますか？

Redisは、2024年3月にバージョン7.4以降のライセンスを従来の3条項BSDライセンスから、**Redis Source Available License v2（RSALv2）**および**Server Side Public License v1（SSPLv1）**のデュアルライセンスに変更しました。 citeturn0search1

**RSALv2**では、ソフトウェアの使用、コピー、配布、派生物の作成が許可されていますが、**商用サービスとして第三者に提供すること**が禁止されています。これにより、AWSやGCP、Azureなどのクラウドサービスプロバイダーは、Redis製品を無料で使用することができなくなります。 citeturn0search1

一方、**SSPLv1**は、ソフトウェアをサービスとして提供する場合、そのソースコードだけでなく、サービス運用に関連するすべてのソフトウェアのソースコードを公開することを要求するライセンスです。これにより、商用サービスとしてRedisを利用する際の制約が強化されています。 citeturn0search2

**個人や企業が内部でRedisを使用する場合**、これらのライセンス変更による影響はほとんどありません。つまり、**商用環境で無料でRedisを使用することは引き続き可能**です。ただし、Redisを第三者に対してサービスとして提供する場合、特にクラウドサービスとして提供する場合には、上記のライセンス条件に注意が必要です。

なお、ライセンス変更前のRedis 7.4以前のバージョンは、従来の3条項BSDライセンスのままであり、引き続き使用可能です。しかし、これらのバージョンは将来的にセキュリティアップデートや新機能の提供が制限される可能性があるため、最新バージョンの使用を検討する際には、ライセンス条件を十分に確認することが重要です。 citeturn0search3
